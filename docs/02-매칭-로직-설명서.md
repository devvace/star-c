## 1. 목적과 범위

- 입력 조건으로부터 매칭 대상자 수, 예상 등록 인원, 예상 소요기간, 권장 실시기관을 구하는 방법을 설명함
- 매칭은 하드필터 방식만 사용함. 조건이 모두 맞는 대상자만 세고, 가중치나 유사도 점수는 쓰지 않음
- 자연어 조건 해석과 참여 이력 가중(소프트 스코어링)은 본 과제 범위 밖임
- 매칭 쿼리 원본은 소스의 `src/db/match.sql`, 예측 계산은 `src/predict.ts`, 고정값은 `data/params.csv`와 `src/config.ts`에 있음

## 2. 입력 조건

| 항목 | 입력 방식 | 값 | 매칭에서의 역할 |
|---|---|---|---|
| 연령 범위 | 드롭다운 | 10세 구간 6개 (19~29세 … 70세 이상) | 대상자 만 나이가 구간 안에 있어야 함 |
| 성별 | 라디오 | 남성 / 여성 / 성별무관 | 성별무관이면 성별 조건을 적용하지 않음 |
| 건강인/환자 구분 | 라디오 | 건강인 / 환자 | 대상자 건강상태와 같아야 함 |
| 질환 카테고리 | 드롭다운 | 6종 (고혈압, 이상지질혈증, 당뇨병, 아토피피부염, 건선, 기타) | 환자일 때만 적용. 기타는 질환명 직접 입력 가능 |
| 목표 지역 | 체크박스(복수) | 시도 17개 | 대상자 거주 시도가 선택한 지역 중 하나여야 함 |
| 목표 대상자 수 | 숫자 | 1 이상 정수 | 매칭에는 쓰지 않음. 소요기간과 달성률 계산에 사용 |

- 목표 지역을 하나도 고르지 않거나 목표 대상자 수가 1 미만이면 리포트를 만들지 않음

## 3. 하드필터 매칭 규칙

### 3.1 기본 규칙

- 매칭 변수 5종(연령, 성별, 거주지역, 건강상태, 질환)이 **모두** 일치하는 대상자만 셈 (AND 조건)
- 그에 앞서 매칭 활용에 동의한 대상자(`consent_matching = 1`)만 대상으로 함
- 결과는 시도별 인원 수로만 집계함. 대상자 개별 행은 화면이나 기록에 내보내지 않음

### 3.2 예외 규칙

| 상황 | 처리 |
|---|---|
| 건강인을 선택 | 질환 조건을 적용하지 않음 (건강인은 질환 값이 없음) |
| 성별무관을 선택 | 성별 조건을 적용하지 않음. 결과는 남성 결과와 여성 결과의 합과 같음 |
| 질환을 `기타`로 선택하고 질환명을 입력 | 대상자의 세부 질환명(`disease_detail`)에 입력한 글자가 포함되어야 함 (부분 일치) |
| 질환을 `기타`로 선택하고 질환명을 비움 | `기타`에 속한 모든 대상자가 매칭됨 |
| 70세 이상 선택 | 만 70세 이상 전체 (상한 없음) |

### 3.3 쿼리 원문

콘솔은 아래 SQL 하나로 매칭과 시도별 집계를 처리함. `:`로 시작하는 값은 입력 화면에서 넘어오는 조건임.

```sql
SELECT sido_code, COUNT(*) AS n
FROM subjects
WHERE consent_matching = 1                                          -- 전처리: 매칭 활용 동의자만
  AND age BETWEEN :age_min AND :age_max                             -- ① 연령
  AND (:sex = 'A' OR sex = :sex)                                    -- ② 성별 (성별무관이면 적용하지 않음)
  AND sido_code IN (SELECT value FROM json_each(:regions))          -- ③ 거주지역
  AND health_status = :health_status                                -- ④ 건강상태
  AND (                                                             -- ⑤ 질환 (건강인이면 적용하지 않음)
    :health_status = '건강인'
    OR (
      disease_category = :disease
      AND (:disease <> '기타' OR :disease_detail = '' OR instr(disease_detail, :disease_detail) > 0)
    )
  )
GROUP BY sido_code
ORDER BY n DESC, sido_code;
```

줄별 설명

| 줄 | 의미 |
|---|---|
| `consent_matching = 1` | 동의한 대상자만 남김 |
| `age BETWEEN :age_min AND :age_max` | 선택한 연령 구간 안의 나이. 70세 이상은 70~200으로 넘김 |
| `(:sex = 'A' OR sex = :sex)` | 성별무관(`A`)이면 항상 참, 아니면 성별이 같아야 함 |
| `sido_code IN (…json_each(:regions))` | 선택한 시도 코드 목록(JSON 배열) 안에 있어야 함 |
| `health_status = :health_status` | 건강인/환자가 같아야 함 |
| `:health_status = '건강인' OR (…)` | 건강인이면 질환 조건을 건너뜀 |
| `disease_category = :disease` | 질환 카테고리가 같아야 함 |
| `:disease <> '기타' OR :disease_detail = '' OR instr(…) > 0` | 기타가 아니거나, 질환명을 안 적었거나, 적은 글자가 세부 질환명에 포함되면 통과 |
| `GROUP BY sido_code` | 시도별 인원 수로 집계. 매칭 대상자 수는 이 값들의 합 |

## 4. 예상 등록 인원

```
예상 등록 인원 = 매칭 대상자 수 × 예상 반응률 × 예상 스크리닝 통과율
```

- 반응률과 통과율은 질환별 고정값이며 `params` 테이블에서 읽음. 건강인은 `건강인` 행을 씀
- 소수점 첫째 자리까지 표시 (예: 2.925 → 2.9명)
- 현재 값 (가상 시나리오 값)

| 구분 | 반응률 | 통과율 | 곱 |
|---|---|---|---|
| 고혈압 | 45% | 65% | 0.293 |
| 이상지질혈증 | 45% | 65% | 0.293 |
| 당뇨병 | 40% | 55% | 0.220 |
| 아토피피부염 | 50% | 60% | 0.300 |
| 건선 | 45% | 55% | 0.248 |
| 기타 | 35% | 50% | 0.175 |
| 건강인 | 50% | 70% | 0.350 |

## 5. 예상 소요기간

### 5.1 가정

| 항목 | 값 | 의미 |
|---|---|---|
| 접촉 기간 | 3개월 | 현재 매칭된 대상자 전원에게 연락하고 스크리닝을 마치는 데 걸리는 기간 |
| 월 신규 유입률 | 15% | 접촉 기간이 끝난 뒤 매달 새로 들어오는 매칭 대상자 수 = 현재 예상 등록 인원 × 15% |
| 표시 상한 | 24개월 | 이보다 길면 "24+개월"로 표시 |

### 5.2 계산

E = 예상 등록 인원, T = 목표 대상자 수

| 경우 | 조건 | 소요기간 | 화면 표시 |
|---|---|---|---|
| 산출 불가 | E = 0 | 계산하지 않음 | "—", 산출 불가 |
| 현재 대상자로 달성 | E ≥ T | 3 × T ÷ E (개월) | 1개월 미만이면 주 단위로 표시 (개월 × 4.3, 최소 1주) |
| 신규 유입 필요 | E < T | 3 + (T − E) ÷ (E × 0.15) (개월) | 소수점 첫째 자리 |
| 달성 곤란 | 위 결과가 24개월 초과 | — | "24+개월" |

- 목표 달성률 = min(1, E ÷ T), 백분율로 표시

## 6. 권장 실시기관

### 6.1 대상 기관

입력한 질환(건강인이면 `건강인`)을 수행하는 기관만 후보로 둠. 기관 목록은 가상이며 `src/config.ts`에 있음.

| 기관 | 소재 | 수행 질환 |
|---|---|---|
| 부산 A대학교병원 임상시험센터 | 부산 | 고혈압, 당뇨병, 이상지질혈증, 건선, 건강인 |
| 부산 B대학교병원 | 부산 | 아토피피부염, 건선, 당뇨병, 기타 |
| 부산 C종합병원 | 부산 | 고혈압, 이상지질혈증, 기타 |

| 경남 E대학교병원 (양산) | 경남 | 아토피피부염, 건선, 고혈압, 건강인 |
| 경남 F종합병원 (창원) | 경남 | 고혈압, 당뇨병, 이상지질혈증 |

| 대구 H대학교병원 | 대구 | 건선, 아토피피부염, 고혈압, 기타 |
| 서울 I대학교병원 | 서울 | 고혈압, 이상지질혈증, 당뇨병, 아토피피부염, 건선, 기타, 건강인 |
| 경기 J대학교병원 | 경기 | 고혈압, 당뇨병, 아토피피부염, 기타 |

### 6.2 점수

```
점수 = 매칭률 × 0.6 + 접근성 × 0.4
```

| 지표 | 계산 |
|---|---|
| 매칭률 | 기관이 있는 시도에 사는 매칭 대상자 수 ÷ 전체 매칭 대상자 수 |
| 접근성 | 매칭 대상자별 근접도의 평균. 근접도는 같은 시도 1.0, 같은 권역 0.6, 그 외 0.2 |

- 권역: 동남권(부산, 울산, 경남), 수도권(서울, 인천, 경기), 대경권(대구, 경북), 충청권(대전, 세종, 충북, 충남), 호남권(광주, 전북, 전남), 강원권, 제주권
- 점수가 높은 순으로 5곳을 표시. 점수가 같으면 기관 소재 시도의 매칭 대상자가 많은 기관, 그것도 같으면 위 목록 순서
- 매칭 대상자가 0명이면 기관을 표시하지 않음

## 7. 계산 예시

입력: 50~59세, 남성, 환자, 고혈압, 목표 지역 부산·경남·울산, 목표 3명 (콘솔의 기본 예시 조건)

### 7.1 매칭

- 가상 데이터 300명 중 동의자(전원)에서 만 50~59세, 남성, 고혈압 환자, 거주지가 부산·경남·울산인 대상자를 셈
- 결과: 부산 8명, 경남 2명, 울산 0명 → 매칭 대상자 수 **10명**

### 7.2 예상 등록 인원

- 고혈압 반응률 45%, 통과율 65%
- 10 × 0.45 × 0.65 = 2.925 → **2.9명**

### 7.3 예상 소요기간

- E = 2.925 < T = 3 이므로 신규 유입 필요
- 3 + (3 − 2.925) ÷ (2.925 × 0.15) = 3 + 0.075 ÷ 0.43875 = 3.17 → **3.2개월**
- 목표 달성률 = 2.925 ÷ 3 = 0.975 → **98%**

### 7.4 권장 실시기관

고혈압을 수행하는 기관 8곳이 후보. 매칭 대상자 10명 중 부산 8명, 경남 2명.

| 기관 | 소재 | 매칭률 | 접근성 | 점수 |
|---|---|---|---|---|
| 부산 A대학교병원 임상시험센터 | 부산 | 8 ÷ 10 = 0.80 | (8 × 1.0 + 2 × 0.6) ÷ 10 = 0.92 | 0.80 × 0.6 + 0.92 × 0.4 = **0.85** |
| 부산 C종합병원 | 부산 | 0.80 | 0.92 | **0.85** |
| 경남 D대학교병원 (진주) | 경남 | 2 ÷ 10 = 0.20 | (8 × 0.6 + 2 × 1.0) ÷ 10 = 0.68 | 0.20 × 0.6 + 0.68 × 0.4 = **0.39** |
| 경남 E대학교병원 (양산) | 경남 | 0.20 | 0.68 | **0.39** |
| 경남 F종합병원 (창원) | 경남 | 0.20 | 0.68 | **0.39** |
| 대구 H대학교병원 | 대구 | 0 | 10 × 0.2 ÷ 10 = 0.20 | 0.08 |
| 서울 I대학교병원 | 서울 | 0 | 0.20 | 0.08 |
| 경기 J대학교병원 | 경기 | 0 | 0.20 | 0.08 |

- 상위 5곳: 부산 A, 부산 C, 경남 D, 경남 E, 경남 F
- 부산 A와 C는 점수와 매칭 인원이 같아 목록 순서대로 표시

### 7.5 같은 조건에서 성별무관을 선택한 경우

- 매칭 대상자 16명 (부산 12, 경남 4), 예상 등록 4.7명, 소요기간 1.9개월 (현재 대상자로 달성), 달성률 100%

## 8. 검증

- 제공받은 프로토타입과 같은 입력에 같은 결과가 나오는지 대조함
  - 조건 조합 50,184개 (연령 6 × 성별 2 × 질환 6종과 건강인 × 기타 질환명 입력 여부 × 지역 조합 41 × 목표 인원 6)
  - 비교 항목: 매칭 대상자 수, 시도별 분포, 예상 등록 인원, 소요기간과 판정, 기관별 매칭률·접근성·점수
  - 결과: 모든 항목 일치. 점수가 같은 기관들의 표시 순서만 12개 조건에서 다르며, 이는 본 콘솔이 동점 기준(6.2절)을 명시적으로 두었기 때문임
- 성별무관 결과가 남성 결과와 여성 결과의 합과 같은지 96개 조건에서 확인함. 전부 일치
- 동의 조건은 가상 데이터가 전원 동의라 결과에 영향이 없으며, 일부를 미동의로 바꾸면 그만큼 제외됨을 별도 확인함
