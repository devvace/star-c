# STAR-C 파일럿 콘솔 — 설치 및 사용 안내

임상시험 의뢰자용 모집 가능성 예측 콘솔의 파일럿 버전입니다.
**프로그램을 설치할 필요가 없습니다.** 파일 하나를 받아서 더블클릭하면 웹브라우저에서 바로 열립니다.
인터넷 연결도 필요 없고, 가상 데이터 300명으로 동작하며 실제 대상자 DB와는 연결되어 있지 않습니다.

## 준비물

- Windows 10 또는 11 PC
- 웹브라우저: Microsoft Edge(윈도우 기본 탑재) 또는 Chrome
- 파일 1개: `index.html` (약 4MB)

## 1. 파일 받기

파일을 이메일이나 메신저로 받은 경우:

1. 첨부된 `index.html`을 클릭해 **다운로드**합니다.
2. 보통 `다운로드` 폴더에 저장됩니다. 찾기 쉽게 **바탕화면**이나 `문서` 폴더로 옮겨 두면 좋습니다.
3. 파일 이름은 바꿔도 됩니다. 예: `STAR-C 콘솔.html` (끝의 `.html`은 남겨 두세요)

압축 파일(.zip)로 받은 경우: 압축 파일을 **먼저 풀고** 나서 안에 있는 `index.html`을 사용하세요. 압축 파일 안에서 바로 열면 동작하지 않습니다.

## 2. 열기

1. `index.html` 파일을 **더블클릭**합니다.
2. Edge 또는 Chrome 창이 열리고 "STAR-C" 화면이 나타납니다. 처음 열 때 1~2초 정도 걸릴 수 있습니다.

더블클릭했는데 다른 프로그램(메모장 등)이 열리면:
파일에서 **마우스 오른쪽 버튼 → 연결 프로그램 → Microsoft Edge** (또는 Google Chrome)를 선택합니다.

## 3. 사용 방법

화면 위쪽에 탭이 세 개 있습니다.

**① 조건 입력**
연령, 성별, 건강인/환자, 질환, 목표 지역, 목표 대상자 수를 고릅니다.
오른쪽에 조건에 맞는 대상자 수가 바로 표시됩니다.
각 항목 이름 옆의 파란 `!` 버튼을 누르면 설명이 나옵니다.
**[예측 리포트 생성]** 버튼을 누르면 결과 화면으로 넘어갑니다.

**② 예측 리포트**
매칭 대상자 수, 예상 등록 인원, 예상 소요기간, 목표 달성률, 지역별 분포, 권장 실시기관을 보여 줍니다.
**[조건 수정]** 버튼으로 입력 화면에 돌아갈 수 있습니다.

**관리 (로그 및 설정)**
오른쪽 위 **접속 권한**을 `신트리아 관리자`로 바꾸면 열립니다.
- 사용 기록: 누가 언제 무엇을 조회했는지 목록. **[CSV 내보내기]**를 누르면 엑셀로 열 수 있는 파일이 `다운로드` 폴더에 저장됩니다.
- 고정 파라미터: 예상 등록 인원 계산에 쓰는 질환별 비율
- 데이터 현황: 들어 있는 가상 데이터의 구성

## 자주 묻는 질문

**화면이 안 뜨고 흰 화면만 보여요.**
파일이 완전히 다운로드되지 않았을 수 있습니다. 파일 크기가 약 4MB인지 확인하고, 아니면 다시 받아 주세요.

**"이 파일은 개발용 원본이라 화면이 동작하지 않습니다"라는 빨간 글씨가 나와요.**
잘못된 파일입니다. 소스 폴더 안의 `index.html`이 아니라 **`dist` 폴더 안의 `index.html`**을 받아야 합니다. 보내 준 사람에게 `dist/index.html`을 다시 요청하세요.

**사용 기록이 다른 PC에서는 안 보여요.**
사용 기록은 그 PC의 그 브라우저 안에만 저장됩니다. 다른 PC나 다른 브라우저(Edge ↔ Chrome)에서는 보이지 않습니다. 기록을 모으려면 CSV 내보내기로 파일을 저장해 두세요.

**브라우저를 닫으면 입력한 조건이 사라져요.**
정상입니다. 다시 열면 예시 조건(50~59세 남성 고혈압, 부산/경남/울산, 목표 3명)으로 시작합니다. 사용 기록은 남아 있습니다.

**회사 PC에서 파일이 차단돼요.**
파일 **오른쪽 버튼 → 속성** 아래쪽에 "차단 해제" 체크박스가 있으면 체크하고 **확인**을 누른 뒤 다시 열어 보세요. 그래도 안 되면 회사 보안 정책일 수 있으니 IT 담당자에게 `.html` 파일 열기를 문의하세요.

**인터넷이 끊겨도 되나요?**
됩니다. 외부 서버에 접속하지 않습니다.

**글꼴이 홈페이지와 달라 보여요.**
글꼴(Pretendard)이 파일 안에 들어 있어서 어느 PC에서나 같게 보여야 합니다. 다르게 보이면 브라우저가 너무 오래된 버전일 수 있으니 Edge 또는 Chrome을 최신으로 업데이트해 주세요.

## 개발자용: 직접 빌드하기

일반 사용자는 이 부분을 볼 필요가 없습니다.

```
npm ci
npm run build        # → dist/index.html
npm run gen:data     # data/*.csv 다시 생성 (보통 필요 없음)
```

Node.js 20 이상이 필요합니다. 데이터(`data/*.csv`)를 바꾸면 반드시 다시 빌드해야 결과물에 반영됩니다. 자세한 구조와 작업 이력은 `CLAUDE.md`를 보세요.
